## Description
An overview of all garrisons on your account.

Currently only as broker for addons like Titan Panel.
This is a early version and only display the level of the garrison building and shipyard.
* Gray > Has no garrison / shipyard.
* Green > Garrison / shipyard level 1
* Blue > Garrison / shipyard level 2
* Purple > Garrison / shipyard level 3
